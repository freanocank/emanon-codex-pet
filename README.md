# Emanon for Codex · 爱玛侬桌宠

[English](#english) · [简体中文](#简体中文)

![Emanon tilts her head back while smoking](assets/idle-preview.gif)

## English

A monochrome pixel-art companion for Codex inspired by Emanon from *Memories of Emanon*, written by Shinji Kajio and illustrated by Kenji Tsuruta. [Manga edition](https://bookwalker.jp/de9e83e41b-bd9c-4d2a-9aa9-7285209fb872/)

She tilts her head back while smoking in a six-frame idle loop. The pose lasts about 2.34 seconds at the normal Codex idle cadence. The package uses the v2 companion format with nine animation states and 16 gaze directions.

### Install

1. [Download the ZIP](downloads/emanon-codex-pet.zip?raw=true) and extract it.
2. Place the `emanon/` folder in `~/.codex/pets/`. If you use a custom `CODEX_HOME`, place it in that directory’s `pets/` folder.
3. Select **爱玛侬** (Emanon) in the Codex pet picker.

## 简体中文

以梶尾真治原作、鹤田谦二作画的《回忆爱玛侬》为灵感制作的 Codex 黑白像素桌宠。 [漫画版本](https://bookwalker.jp/de9e83e41b-bd9c-4d2a-9aa9-7285209fb872/)

待机时，爱玛侬会仰头抽烟。在 Codex 的常规待机节奏下，她会保持这个姿势约 2.34 秒。桌宠使用 v2 格式，包含 9 组动作和 16 个视线方向。

### 安装

1. [下载安装包](downloads/emanon-codex-pet.zip?raw=true)并解压。
2. 将 `emanon/` 文件夹放入 `~/.codex/pets/`。如果设置了 `CODEX_HOME`，放入对应目录下的 `pets/` 文件夹。
3. 在 Codex 的桌宠列表里选择 **爱玛侬**。
